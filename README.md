# Мой заработок: локальное PWA для iPhone

## Что внутри
- Календарь рабочих смен по месяцам
- Месячная цель и динамический план на оставшиеся смены
- Касса, расходы и чистый итог за смену
- Прогресс, средний заработок, прогноз, лучшие/слабые смены
- Локальное сохранение через localStorage
- Экспорт и импорт резервной копии
- Офлайн-режим после первой загрузки (Service Worker)

## Важно про установку
PWA нельзя полноценно установить на главный экран iPhone прямо из ZIP или через открытие `index.html` как локального файла. Нужен HTTPS-адрес. Разместите содержимое папки на статическом HTTPS-хостинге (например, GitHub Pages, Cloudflare Pages или Netlify), затем откройте адрес в Safari на iPhone и выберите:
Поделиться -> На экран «Домой».

После первой загрузки приложение сможет открываться офлайн. Данные хранятся локально в Safari на этом устройстве. Очистка данных Safari может их удалить, поэтому периодически делайте экспорт резервной копии.

## Принцип расчёта
Касса минус расходы = чистый заработок. Чистый заработок завершённых смен уменьшает остаток месячной цели; остаток делится поровну между незаполненными запланированными сменами. Запланированная смена считается завершённой, когда сохранена касса (включая 0).
